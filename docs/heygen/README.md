# `docs/heygen/` — a base de conhecimento do HeyGen

Cinco documentos sobre avatar de IA no HeyGen, montados **só a partir de fonte oficial**:
Central de Ajuda, docs v3 de API/MCP, HeyGen Academy em pt-BR e os guias da comunidade oficial.
Cada afirmação linka a página de onde veio — nada de tutorial de YouTube ou "eu vi funcionar".

## Ordem de leitura

1. **[`LEIA-PRIMEIRO.md`](LEIA-PRIMEIRO.md)** — o mapa da pasta e as 10 armadilhas que mais
   derrubam quem não leu. Comece aqui.
2. **[`TEMPLATES-PRONTOS.md`](TEMPLATES-PRONTOS.md)** — moldes para preencher e usar hoje.
3. **[`BIBLIOTECA-DE-PROMPTS.md`](BIBLIOTECA-DE-PROMPTS.md)** — a fórmula por trás de cada molde.
4. **[`REGRAS-E-LIMITES.md`](REGRAS-E-LIMITES.md)** — o placar de números: crédito, limite de
   plano, consentimento, código de erro.
5. **[`INDICE-FONTES.md`](INDICE-FONTES.md)** — o catálogo navegável das páginas oficiais.

## Isto é a fonte, não o passo a passo

O workflow completo — do roteiro ao vídeo pronto — está em
**[`AVATAR-IA.md`](../../AVATAR-IA.md)**, na raiz do pacote. Quando os dois divergirem, a fonte
manda e o guia é que tem que ser corrigido.

## O que é nosso e o que é do HeyGen

O texto das páginas oficiais é do HeyGen e **não é republicado aqui** — as transcrições literais não
acompanham este pacote público. O que você lê nestes documentos é **nosso**: a análise, a paráfrase
das regras e os exemplos escritos por nós. Do HeyGen entram só **citações curtas**, entre aspas e
com atribuição, e sempre com o link para a página de origem, na versão de hoje.
